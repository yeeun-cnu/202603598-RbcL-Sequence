# 202603598-RbcL-Sequence

식물 6종의 RbcL 단백질 서열을 비교하여 아미노산 보존성과 종간 차이를 분석하는 프로젝트입니다.

## 1. 프로젝트 개요

RbcL(Ribulose-1,5-bisphosphate carboxylase/oxygenase large subunit)은 광합성의 탄소 고정 과정에 관여하는 루비스코(Rubisco)의 대단위체입니다. 본 프로젝트에서는 서로 다른 식물 6종의 RbcL 단백질 서열을 수집하고, 서열 정렬과 위치별 비교를 통해 공통적으로 보존된 아미노산과 종에 따라 달라지는 부분을 살펴봅니다.

## 2. 연구 목적 및 질문

- 식물 6종의 RbcL 단백질 서열은 어느 정도 유사한가?
- 여러 종에서 공통적으로 유지되는 아미노산 위치는 어디인가?
- 종에 따라 차이가 나타나는 위치와 그 양상은 어떠한가?

## 3. 분석 대상 및 데이터

- 분석 대상: 식물 6종의 RbcL 단백질 서열
- 데이터 출처: NCBI Protein 데이터베이스
- 데이터 형식: FASTA
- 수집할 메타데이터: 종명, accession number, 단백질 서열, 서열 길이 및 데이터베이스 설명

각 서열은 종명과 accession number를 함께 기록하여 출처를 추적할 수 있도록 합니다. 수집 후에는 중복 서열, 불완전한 서열, 비정상적인 아미노산 문자가 포함된 서열이 있는지 확인합니다.

## 4. 연구 진행 방법

### 4.1. 단백질 서열 수집 및 전처리
NCBI Protein 데이터베이스에서 각 식물 종의 RbcL 단백질 서열을 확보합니다. FASTA 형식으로 저장하고, 서열의 길이와 아미노산 문자를 확인하여 분석에 사용할 데이터를 정리합니다.

### 4.2. 쌍별 서열 정렬
Needleman-Wunsch 알고리즘을 이용하여 두 단백질 서열을 전역 정렬합니다. 이를 통해 서열 사이의 유사한 부분과 삽입·결실에 해당하는 차이를 비교할 수 있도록 합니다.

### 4.3. 다중 서열 정렬
쌍별 정렬 결과를 바탕으로 Center-Star 방식의 다중 서열 정렬(Multiple Sequence Alignment, MSA)을 구현합니다. 여러 서열을 공통된 위치 기준으로 정렬하여 종 사이의 아미노산을 같은 열에서 비교할 수 있도록 합니다.

### 4.4. 아미노산 보존성 분석
정렬된 서열에서 각 위치의 아미노산 분포를 계산합니다. 각 위치에서 가장 많이 나타나는 아미노산과 출현 비율을 확인하여 보존성이 높은 위치와 변이가 많은 위치를 구분합니다.

### 4.5. 종간 유사도 및 결과 해석
정렬 결과를 바탕으로 서열 간 유사도를 비교하고, 식물 종 사이에서 공통점과 차이점을 정리합니다. 분석 결과는 표와 그래프로 나타내어 해석합니다.

## 5. 구현 계획

- Python을 사용하여 서열 처리 및 정렬 알고리즘을 구현합니다.
- 기본 자료형, 조건문, 반복문, 함수, 리스트, 딕셔너리 및 파일 입출력을 활용합니다.
- Needleman-Wunsch 쌍별 정렬과 Center-Star 다중 서열 정렬의 핵심 과정을 직접 작성합니다.
- 각 단계의 입력과 출력이 확인되도록 코드를 모듈별로 구성합니다.

## 9. 유의 사항

Center-Star 방식은 여러 서열을 정렬하기 위한 실용적인 접근법이지만, 가능한 모든 다중 서열 정렬 중 전역적으로 최적의 결과를 보장하지는 않습니다. 또한 서열 유사도만으로 단백질의 기능이나 생물학적 특성이 완전히 동일하다고 결론 내리지 않으며, 분석 대상이 6종이라는 점을 고려하여 결과를 해석합니다.
